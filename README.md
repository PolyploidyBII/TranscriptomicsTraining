## Overview

This repo contains training materials on how to analyze RNA-seq data
generated in the context of the PI3 project. Here, we demonstrate how to:

1. Obtain gene-level transcript abundance estimates across samples.
2. Normalize data by library size and by cell volume (using spike-in controls)
3. Identify differentially expressed genes (DEGs) between different
ploidy levels for different genotypes
4. Perform functional analyses (overrepresentation- and rank-based enrichment 
analysis)
